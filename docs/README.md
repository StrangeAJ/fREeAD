# FreeAD Documentation

This directory contains all documentation for the FreeAD RSS reader application.

## Directory Structure

### /features
Documentation for specific features and capabilities:
- MULTIPLE_SELECTION_FEATURE.md - Multiple article selection functionality
- ENHANCED_ARTICLE_EXTRACTION.md - Enhanced article content extraction
- OPML_FEATURES.md - OPML import/export functionality

### /fixes
Documentation for bug fixes and issue resolutions:
- ANDROID_RSS_FIXES.md - Android-specific RSS parsing fixes
- BUG_FIXES_SUMMARY.md - General bug fixes summary
- BUILD_ISSUES_FIX.md - Build-related issue fixes
- FEED_MANAGEMENT_FIX_SUMMARY.md - Feed management bug fixes

### /guides
Implementation guides and how-to documentation:
- FEED_MANAGEMENT_GUIDE.md - Guide for feed management features
- FEED_MANAGEMENT_IMPLEMENTATION.md - Technical implementation details
- enable_developer_mode.md - Developer mode setup guide

## v3

- V3_OVERHAUL_PLAN.md - architecture and rationale for the v3 rewrite (extraction pipeline, design system, AI layer, screens)
- CHANGELOG.md - release notes, starting at 3.0.0

The /features, /fixes and /guides docs below predate the v3 overhaul and describe v2 behaviour; several of the bugs they document (extraction, feed management) were root-caused and fixed differently in v3 - see CHANGELOG.md.
